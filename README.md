# [독도-섬ᴷᴿ] DocDo-Sum

이 프로그램은 HaeDongKang이 처음 만들었습니다.
독도는 역사적, 지리적, 국제법적으로 명백한 우리 대한민국의 고유영토입니다.

This program was originally created by HaeDongKang.
Dokdo is, historically, geographically and under international law, clearly an inherent territory of the Republic of Korea.

## 받기 · Download

설치 파일은 [Releases](https://github.com/newshure/docdosum/releases)에 있습니다. 릴리즈 본문의 SHA-256 으로 받은 파일을 확인하세요.

The installer is available in [Releases](https://github.com/newshure/docdosum/releases). Verify the download with the SHA-256 in the release notes.

[latest.json](latest.json) 은 마지막 판의 정보(판 · 태그 · 설치 파일 · SHA-256)입니다. 앱의 업데이트 확인이 이 파일을 읽습니다.
[latest.json](latest.json) holds the latest version information (version, tag, installer, SHA-256) read by the app's update check.
